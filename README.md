# Panchapakshi Application

The Panchapakshi Application is a digital tool based on the traditional Panchapakshi Shastra system. It helps users identify the activity and strength of the five symbolic birds:

* Vulture
* Owl
* Crow
* Hen
* Peacock

The application calculates Panchapakshi timings using information such as date, time, location, weekday, and lunar phase. It presents the results through a simple, mobile-friendly interface, making it easier to understand favorable and unfavorable time periods.

## Key Features

* Panchapakshi bird calculation
* Day and night timing divisions
* Jamam and activity-period calculations
* Date, time, and location selection
* Waxing and waning Moon phase support
* Active bird and activity status display
* Clear graphical representation
* Responsive, mobile-friendly design

## Purpose

This project converts traditional Panchapakshi timing calculations into an accessible digital format for learning, research, and personal reference.
